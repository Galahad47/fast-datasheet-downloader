# Datasheet Downloader

Графическое приложение на Python для автоматического поиска и скачивания даташитов (технической документации) электронных компонентов.

## Возможности

- **Множественные источники поиска**: DuckDuckGo, Alldatasheet.com, DatasheetsPDF.com
- **LLM-поиск**: Интеграция с DeepSeek AI для умного поиска даташитов на официальных сайтах производителей
- **Параллельная загрузка**: Многопоточная обработка нескольких компонентов одновременно
- **GUI интерфейс**: Удобный графический интерфейс на базе Tkinter
- **Гибкая настройка**: Конфигурируемые параметры таймаутов, потоков и API-ключей

## Требования

- Python 3.8+
- tkinter (обычно входит в стандартную поставку Python)

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта в локальную директорию

2. Установите зависимости:
```bash
pip install -r main/requirements.txt
```

3. (Опционально) Настройте API-ключ DeepSeek для LLM-поиска:
   - Откройте `main/config.py`
   - Укажите ваш API-ключ в переменной `DEEPSEEK_API_KEY`
   - Или установите переменную окружения `DEEPSEEK_API_KEY`

## Использование

### Запуск приложения

```bash
cd main
python main.py
```

### Работа с приложением

1. **Импорт списка компонентов**:
   - Введите названия компонентов в текстовое поле (каждое с новой строки)
   - Нажмите "Вставить список" или "Загрузить TXT" для импорта из файла

2. **Выбор компонентов**:
   - Нажмите на кнопки с названиями компонентов для выбора/снятия выбора
   - Используйте "Выбрать все" или "Очистить выделение" для массовых операций

3. **Настройка папки загрузки**:
   - Укажите путь для сохранения даташитов (по умолчанию: `./datasheets`)

4. **Загрузка**:
   - Нажмите "Скачать datasheets" для начала процесса
   - Следите за прогрессом в логе

## Конфигурация

Основные параметры в `main/config.py`:

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `SEARCH_URL_DDG` | URL поиска DuckDuckGo | https://html.duckduckgo.com/html/ |
| `REQUEST_TIMEOUT` | Таймаут запросов (сек) | 25 |
| `MAX_RETRIES` | Количество повторных попыток | 2 |
| `MAX_WORKERS_TOTAL` | Макс. количество потоков загрузки | 5 |
| `DEEPSEEK_API_KEY` | API-ключ DeepSeek | '' |
| `USE_LLM_AS_FALLBACK` | Использовать LLM как резервный поиск | True |

## Принцип работы

1. **Поиск прямых ссылок**: Параллельный опрос источников для нахождения прямых PDF-ссылок
2. **Fallback-режим**: Если прямая ссылка не найдена, выполняется:
   - Сбор кандидатов с оценкой релевантности
   - Парсинг страниц в поисках PDF
   - LLM-поиск (если включён и доступен)
3. **Валидация**: Проверка Content-Type и эвристический анализ URL

## Ограничения

- Некоторые сайты могут блокировать автоматические запросы
- LLM-поиск требует действительный API-ключ DeepSeek
- GUI требует наличия дисплея (не работает в headless-режиме)
