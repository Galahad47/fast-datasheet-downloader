# Universal Info Searcher / Универсальный поисковик информации

Графическое приложение на Python для автоматического поиска и скачивания различной информации по множеству тематик: от технической документации до новостей и обсуждений на форумах.

## 🚀 Возможности

### Поддерживаемые типы информации

| Тип | Описание | Формат | Примеры использования |
|-----|----------|--------|----------------------|
| **Даташит** | Техническая документация компонентов | PDF | `STM32F103C8T6`, `LM358` |
| **Приложение** | Примеры применения, схемы, рекомендации | PDF | `Arduino motor control`, `LED driver circuit` |
| **Руководство** | Инструкции пользователя | PDF | `Raspberry Pi setup guide`, `3D printer manual` |
| **Технический документ** | Исследования, аналитика, whitepapers | PDF | `Machine learning trends 2024`, `IoT security` |
| **Обзор** | Сравнения, тесты, ревью | HTML | `RTX 4090 review`, `Best smartphones 2024` |
| **Форум** | Обсуждения, вопросы сообщества | HTML | `Python async best practices`, `ESP32 WiFi issues` |
| **Новости** | Последние анонсы и события | HTML | `AI breakthrough`, `New processor release` |
| **Пользовательский** | Любой ваш запрос | Любое | `site:github.com awesome-python` |

### Ключевые особенности

- **Множественные источники поиска**: DuckDuckGo, Google Scholar, Bing, прямые запросы к производителям
- **Защита от блокировок**: Автоматическое переключение между поисковыми системами при недоступности, поддержка прокси
- **Параллельная загрузка**: Многопоточная обработка нескольких запросов одновременно
- **GUI интерфейс**: Удобный графический интерфейс на базе Tkinter
- **Гибкая настройка**: Конфигурируемые параметры таймаутов, потоков и доверенных доменов
- **Система оценки релевантности**: Автоматический скоринг источников по ключевым словам и доменам
- **Приоритет официальных источников**: Прямой поиск на сайтах производителей (TI, Analog Devices, STMicroelectronics и др.)

## 🔧 Установка

1. **Клонируйте репозиторий** или скопируйте файлы проекта:
```bash

```

2. **Установите зависимости**:

     ```powershell

     $env:HTTPS_PROXY="http://proxy-server:port"
     ```

## 📖 Использование

### Работа с приложением

#### 1. Импорт списка запросов
- Введите названия/запросы в текстовое поле (каждый с новой строки)
- Нажмите **"Вставить список"** или **"Загрузить TXT"** для импорта из файла

#### 2. Выбор типа информации
По умолчанию используется тип **"Даташит"**. Для изменения:
- Откройте `main/gui.py`
- Найдите строку создания `InfoSearcher` и измените параметр `info_type`:
  ```python
  searcher = InfoSearcher(out_dir, log_callback=self.log, info_type="review")
  ```
- Или передайте тип через командную строку (требуется доработка)

#### 3. Выбор элементов
- Нажимайте на кнопки с названиями для выбора/снятия выбора
- Используйте **"Выбрать все"** или **"Очистить выделение"** для массовых операций

#### 4. Настройка папки загрузки
- Укажите путь для сохранения файлов (по умолчанию: `./datasheets`)

#### 5. Загрузка
- Нажмите **"Скачать"** для начала процесса
- Следите за прогрессом в окне лога

## ⚙️ Конфигурация

Основные параметры в `main/config.py`:

### Сетевые настройки
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `REQUEST_TIMEOUT` | Таймаут запросов (сек) | 25 |
| `MAX_RETRIES` | Количество повторных попыток | 2 |
| `RETRY_BACKOFF_FACTOR` | Множитель задержки между попытками | 1.5 |

### Параллелизм
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `MAX_WORKERS_PER_SOURCE` | Потоков на один источник | 3 |
| `MAX_WORKERS_TOTAL` | Всего одновременных задач | 5 |

### Источники поиска
| Источник | Описание | Статус |
|----------|----------|--------|
| DuckDuckGo | Анонимный поиск через HTML-версию | ✅ Активен |
| Google Scholar | Научные статьи и техническая документация | ✅ Активен |
| Bing | Резервный поисковик с поддержкой site: запросов | ✅ Активен |
| Прямые запросы к производителям | Поиск на официальных сайтах (ti.com, analog.com и др.) | ✅ Активен |
| Alldatasheet | Специализированная база даташитов | ⚠️ Временно отключен (403 ошибки) |
| Datasheetspdf | Another datasheet database | ❌ Недоступен (домен не resolves) |

### Типы информации
Конфигурация типов находится в словаре `INFO_TYPES`:
```python
INFO_TYPES = {
    "datasheet": {
        "name": "Даташит",
        "description": "Техническая документация компонента",
        "file_extension": ".pdf",
        "keywords": ["datasheet", "specification", "technical documentation"],
        "llm_prompt_template": "Найди прямую ссылку на PDF-файл даташита для компонента: {query}",
    },
    # ... другие типы
}
```

### Доверенные домены
Для каждого типа можно задать список предпочтительных доменов в `TRUSTED_DOMAINS`:
```python
TRUSTED_DOMAINS = {
    "datasheet": ["ti.com", "analog.com", "st.com", ...],
    "review": ["tomshardware.com", "anandtech.com", ...],
    # ...
}
```

## 🔍 Принцип работы

### Алгоритм поиска

1. **Параллельный опрос источников**
   - DuckDuckGo (HTML-версия для всех типов)
   - Google Scholar (научные статьи и техническая документация)
   - Bing (резервный источник с поддержкой site: запросов)
   - Прямые запросы к производителям через Bing (только для datasheet)

2. **Проверка типа контента**
   - Для PDF: проверка Content-Type через HEAD-запрос
   - Для HTML: проверка доступности страницы

3. **Fallback-режим** (если прямая ссылка не найдена)
   - Сбор кандидатов с оценкой релевантности
   - Парсинг страниц в поисках целевых ссылок
   - Приоритет официальным источникам (производители компонентов)

4. **Система скоринга**
   - +5 за каждое ключевое слово типа
   - +5 за упоминание PDF
   - +10 за доверенный домен
   - +15 за прямой запрос к производителю (datasheet)
   - +3 за совпадение с запросом
   - +7 за явное указание .pdf в URL
   - +3 бонуса для результатов из Google Scholar
   - +2 бонуса для результатов из Bing

## ⚠️ Ограничения

- Некоторые сайты могут блокировать автоматические запросы (CAPTCHA, rate limiting)
- GUI требует наличия дисплея (не работает в headless-режиме без X11 forwarding)
- Качество поиска зависит от точности формулировки запроса
- Google Scholar и Bing могут требовать CAPTCHA при очень частых запросах
- Alldatasheet временно отключен из-за 403 ошибок
- Datasheetspdf недоступен (домен не резолвится)

### Рекомендации по обходу блокировок

1. **Используйте прокси**: Настройте HTTP/HTTPS прокси через переменные окружения
2. **Увеличьте таймауты**: При медленном соединении увеличьте `REQUEST_TIMEOUT` в config.py
3. **Делайте перерывы**: При обработке больших списков делайте паузы между запросами
4. **Используйте разные источники**: Система автоматически переключается между DuckDuckGo, Google Scholar и Bing
